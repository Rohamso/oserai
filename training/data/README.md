# Training data

`tiny_shakespeare.txt` is the bundled scratch-training demo. It is an exact
copy of the subset of William Shakespeare's works distributed by
[karpathy/char-rnn](https://github.com/karpathy/char-rnn/tree/master/data/tinyshakespeare).
It is kept here so contributors can run the small local example.

SHA-256 for the bundled file is
`86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`.

The older training examples retrieve TinyStories and Dolly separately.
Their original terms apply to those datasets. The
[reviewed adaptation pipeline](../../docs/model-adaptation.md) records item and
source provenance for its own corpora and uses a separate license allowlist.
