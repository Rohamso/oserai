# Security policy

## Report a vulnerability privately

Open [OserAI's security advisories](https://github.com/Rohamso/oserai/security/advisories)
and select **Report a vulnerability**. GitHub sends your report privately to the
repository maintainers.

Include the affected component, the commit or version, and the potential impact.
Share sanitized evidence where available and keep credentials, access codes,
private prompts, and personal data out of the report.

Use the private report to coordinate disclosure with the maintainers before
sharing vulnerability details publicly.
